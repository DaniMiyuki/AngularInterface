# Interface Simplificada para Pacientes

Este projeto descreve o desenvolvimento de uma aplicação Single Page Application (SPA) utilizando o framework Angular. A aplicação foi projetada com o objetivo de fornecer uma interface simplificada e acessível para pacientes, permitindo a visualização de resultados de exames, históricos de saúde e relatórios médicos. A interface foi cuidadosamente desenvolvida para ser responsiva e de fácil utilização em dispositivos móveis.

## Funcionalidades

- **Autenticação de Pacientes**: A aplicação implementa um sistema de login seguro, garantindo que cada paciente tenha acesso exclusivo e restrito aos seus próprios dados.
- **Visualização de Resultados**: Os resultados dos exames são apresentados de maneira clara e objetiva, utilizando gráficos e tabelas que facilitam a compreensão por parte dos pacientes.
- **Histórico de Saúde**: O histórico de saúde do paciente é exibido de forma organizada, proporcionando um acompanhamento contínuo e acessível.
- **Perfil do Paciente**: Uma página específica foi dedicada ao perfil do paciente, permitindo a visualização e edição de suas informações pessoais.
- **Notificações e Relatórios**: A interface oferece acesso direto a relatórios médicos e notificações relevantes, assegurando que o paciente esteja sempre informado sobre seu estado de saúde.

## Tecnologias Utilizadas

- **Angular**: Este framework JavaScript foi escolhido para a criação da SPA devido à sua robustez e capacidade de criar experiências de usuário modernas e interativas.
- **TypeScript**: A linguagem TypeScript foi utilizada como base do desenvolvimento, proporcionando tipagem estática e outros recursos avançados que contribuem para a manutenção e escalabilidade do código.
- **Angular CLI**: A ferramenta de linha de comando Angular CLI foi utilizada para facilitar a criação, teste e deploy da aplicação.
- Tailwind: O framework foi empregado para estilização e responsividade da interface, garantindo uma experiência de usuário consistente em diferentes dispositivos.
- **REST API**: A integração com o backend será realizada através de uma API RESTful, permitindo a comunicação eficiente e segura com os dados médicos.

## Requisitos

- **Node.js**: Versão 14.x ou superior foi requisitada para o correto funcionamento do ambiente de desenvolvimento.
- **Angular CLI**: Versão 12.x ou superior foi utilizada para garantir compatibilidade com as funcionalidades mais recentes do Angular.
- **npm**: O gerenciador de pacotes npm, instalado com o Node.js, foi utilizado para gerenciar as dependências do projeto.
